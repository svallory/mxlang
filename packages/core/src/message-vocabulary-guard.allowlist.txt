# Literals the message-vocabulary guard test lets stand.
# One entry per line: file :: function :: fragment -- kind: one-line reason
#
# An entry allows the span its fragment names, in every literal of that
# function that holds it. The guard removes the fragment and checks what is
# left, so a literal that holds an allowed example and also a raw noun or a
# hand-spelled tag is still a hit.
#
# A fragment that starts with `==` allows only a literal that is exactly the
# text after it (a contract key, an internal label), not a longer message that
# happens to contain it.
#
# An entry that matches no hit fails the test, so a migrated site takes its
# entry with it.
#
# Reasons come in five kinds:
#   key       a contract or AST key name, not message text
#   internal  an "IR invariant broken" error: an MX bug report, not a message a dialect's author or user reads
#   mx-tag    text about a tag MX itself defines (<script>, <return>, <for>, <else>, import attributes); those tags keep MX's words
#   example   a syntax example the message shows; the example is written in MX's own syntax
#   register  text for the dialect author at registration, not for the file's author
