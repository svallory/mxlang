---
packages: [core, parser]
kind: Changed
---
Atoms leave core, and a dialect node can now be written inside an expression. A dialect that has atoms (Mesh's `~name`) registers an atom node type and names it from its syntax table's rows; core keeps no atom vocabulary of its own. A node of a registered type claimed inside an expression lowers, through its type's `lower`, to a **forward**: an expression native to the expression language (a Babel node) that takes the node's place in the expression. There is no neutral vocabulary between the node and its forward. `IR_VERSION` is `6`.

- Removed: the `Atom` and `MxAtomMark` types, `Expr.atoms`, a static `Attr`'s `atom` field, the contract attribute type `"atom"` (with `values`, `pattern` and `ref` as atom keys checked by core), core's `mx:Atom` node type, the `ContractAtomOrMember` type, the `{ kind: "atom", name, span }` value of a trigger hook's `ctx.attribute`, core's reading of `extra.mxAtom`, and the registration error for an expression row that names a node type.
- Added: `ExprNode` (`{ type, span, node, forward, code? }`) and `Expr.nodes`, the dialect nodes claimed inside an expression in source order, each with its forward (the very object `Expr.node` holds in its place) and the range of `Expr.code` it is printed at (no range for an attribute method's `function`, `onClick() { return ~a }`, which is printed from its tree rather than spliced; its nodes are still listed). An expression row may name a node type (`node: { type, dialect }`): the parser asks the type to claim the matched text with `ClaimContext.position` `"expression"`, Babel parses the row's stand-in in its place, and a declined text reads as the operand it is. A contract attribute may be typed by a node type the file's dialect registers (`type: "atom:Atom"`, or `type: "array"` with `items: "atom:Atom"`), checked by core at the offending value (``attribute `mode` must be atom:Atom, got string``, ``attribute `list` item 2 must be atom:Atom, got number``, and for a list slot written with one node ``attribute `list` must be array, got atom:Atom; write it as a list: `[~a]` ``); a slot naming an unregistered type is a registration error, and so is a `type` that is neither one of core's types nor a node type key (``Invalid "mode" attribute declaration of tag "pick": `type: "atom"` was removed; declare a node type the file's dialect registers (`atom:Atom`), or `{ type: "array", items: "atom:Atom" }` for a list``). A node type's `lower` returns a fresh forward on each call: core finds the node by the forward's identity. `ctx.attribute(name, node)` accepts a node of a registered type (`{ type: "atom:Atom", span, … }`) and lowers it through its type's `lower` in value position; a node of an unregistered type is a positioned error. `ContractMember` (the former `ContractAtomOrMember`) and `ContractExpression.nodes`.
- Changed: a whole value a value row claimed counts as its node type for every contract slot (``attribute `s` must be string, got atom:Atom``). `cloneIr` keeps each `ExprNode.forward` the same object as the node in the cloned `Expr.node`. Source maps map each forward to its printed range and the text around it one to one. A mark a dialect sets on a forward (`extra.mxAtom`, `extra.mxMember`) reaches every later reader, its own `afterLower` included, unchanged: core no longer reads `extra.mxAtom`, still reads `extra.mxMember`, and strips neither. Both marks go in 0.1.0-alpha.34.
- Migration (a dialect with atoms, Mesh's case): register the atom type (`nodeTypes: { Atom }`, key `mesh:Atom`) and name it from the expression row and the value row, with its `lower` returning `ctx.expression(<string literal>)`; replace a contract `{ type: "atom" }` with `{ type: "mesh:Atom" }` and a list of atoms with `{ type: "array", items: "mesh:Atom" }` (a slot that took one atom or a list is now one of the two: as a list slot, `require=:x` is written `require=[:x]`), and check `values`/`pattern` in the dialect's own contract check; read `attr.node?.type === "mesh:Atom"` for `attr.atom`, and `expr.nodes` for `expr.atoms`; pass `{ type: "mesh:Atom", span, … }` to `ctx.attribute` for `{ kind: "atom", … }`; rename `ContractAtomOrMember` to `ContractMember`. A consumer translating an expression finds a dialect node by identity, `expr.nodes.find(n => n.forward === babelNode)`, rather than by a mark.
