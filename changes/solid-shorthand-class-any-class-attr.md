A tag-shorthand class now merges with any `class=` value on Solid, as it does in Marko and on the other hosts. `<div.a class=y/>`, `<div.a.${x} class=y/>` and concise `div.a class=y` used to stop with "combine shorthand with a string class or use class={...}" unless `y` was a string or an object literal; they now compile to `class={["a", y]}` and render the shorthand first, then the value, joined by a single space. Objects, arrays (nested ones included), numbers, `true`, calls and ternaries all work, and `null`, `undefined`, `false` and `0` add nothing, so `<div.a class=null/>` renders `class="a"`. On a native element an array `class` (merged with a shorthand or written as `class=["a", y]`) is now joined into one string the way Marko joins it, where Solid used to flatten it: `0` printed, `true` was dropped, a repeated word collapsed, a number sorted ahead of the shorthand and a later `{k: false}` removed an earlier `"k"`. A component still receives the array. The error is gone.
