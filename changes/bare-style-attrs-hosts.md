As in Marko, the core `<style>` now refuses attributes on Preact, React, Hono, Solid, Angular and Astro, as it already did on the html target: an authored attribute (`<style media="print">`), a value-less one (`<style scoped>`), a spread (`<style ...attrs>`) and the `#id` and authored `class` shorthands (`<style#a>`, `<style.a class="b">`) are `MX_INVALID_ATTRIBUTE` at the first attribute (at the id word for `<style#a>`), with stock Marko 6.4.4's message: `` The `style` does not support html attributes. For a native html [`<style>` tag](https://markojs.com/docs/reference/core-tag#style) use the `html-style` core tag instead. `` Before, the JSX hosts, Solid and Astro kept the attributes and Angular dropped them silently; Astro's `<style lang="scss">` is refused too (import the stylesheet from the frontmatter instead). Write `<html-style>` for a `<style>` element that keeps its attributes. The file-extension shorthand (`<style.less>`, `<style.module.css>`) is not an attribute and still compiles. The `none` tag-rules preset skips the refusal, and a `style` contract in `customTags` takes the tag as before.
