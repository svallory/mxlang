A Solid compile that fails in lowering (for example a callee's contract error) now attaches the files it read as `dependencies` on the error, as a successful compile returns them, so the language server re-diagnoses the page when the callee changes. A lowercase `oncapture:click` is an ordinary attribute with its full name: it is validated like any attribute, statically and in a spread. A `class=` after a spread (`class=[]`, `class=null`, `class=0` or any dynamic value) now overrides the spread's class, and an empty one prints no class attribute, as in Marko.
